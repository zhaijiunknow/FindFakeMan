## 1. 收容箱

- **只收容「伪人物品」** ✓；一共 **3 格** ✓（`InventoryManager.containmentCapacity`，HUD 那行显示 `已收容/3`）。
- 3 格是硬上限 ✓，所以**玩家必须判断"这件到底该不该拾取"** ✓ —— 不是所有能拿的东西都该进箱子 ✗。
- **丢弃**：选中收容格里已收容的物品 → 右拖「丢弃」→ 清空对应格子 ✓，且**这一局内再也找不回来** ✓（比丢弃一般道具更狠 ✗）。

**拾取的门槛（体感）**：先**选中交互点** → 用**对口道具**交互一次 → **解锁「拾取」** ✓；
在解锁之前，那个交互点上不该出现可拾取的东西 ✗（否则玩家会在没查过的情况下乱收）。

**产地怎么定（已实现 ✓）**：`CaseDirector.PickContainmentHosts` 按**种子**挑 ✓ ——
件数从案情总流摇 ✓（`minContainmentClues` ~ `maxContainmentClues` ✓），产地只在「关键词 ↔ 收容物」**池子**里挑 ✓
（池子是写死的 ✓，因为每件收容物的美术天生绑在某件家具上 ✓ —— 荧光水渍只可能长在水渍上 ✓），
并且**异常家具优先** ✓（读数指哪儿，那里就该收东西 ✓）。
所以：同一颗种子永远同一批产地 ✓（=「部分交互点固定产出」✓）、换种子换位置 ✓、`min` 设 0 时允许某一局一件都不出 ✓。

丑话在前：**「拾取要先用对口工具查过一次」这道门槛还没接** ✗（见 §4 第 2 条 ✓）。
现在只是把收容物挂到了产地上 ✓。

## 2. 工具规则

| 工具 | 用途 | 备注 |
|---|---|---|
| **工具包** | 破坏电子道具与门锁、撬开保险柜 | 共 **5 点耐久** ✓ |
| **紫外线灯** | 显现"伪人用特殊道具隐藏"的物品或笔迹 | 隐藏层可见化 ✓ |
| **便携式探测器** | 探测异常等级；**可还原部分原主人的异常行动场景**（CG） | 见下面的 EMF 表 ✓ |
| **温度计** | 探查温度 | 见下面的温度表 ✓ |
| **录音设备** | 录下**该物品之前发生过事件的所有声音** | 声音本身就是线索 ✓ |

### 2.1 便携式探测器（EMF）判定表

| 等级 | 含义 | 判定方式 |
|---|---|---|
| 1 | 非异常 | 直接排除 ✓ |
| 2 | 轻度疑似异常 | 需结合其它线索：**再有 3 个其它异常**才确定异常 |
| 3 | 中度疑似异常 | **再有 2 个其它异常**才确定异常 |
| 4 | 高度疑似异常 | **再有 1 个其它异常**就确定异常 |
| 5 | **检测异常** | 直接确定异常 ✓，并**出现 CG**，玩家根据 CG 内容自行判断 ✓ |

### 2.2 温度计判定表

| 温度 | 含义 | 判定方式 |
|---|---|---|
| **< 0℃** | **确定异常** | 直接确定 ✓ |
| 0 ~ 10℃ | 重度疑似异常 | **再有 1 个其它异常**才确定异常 |
| 10 ~ 20℃ | 中度疑似异常 | **再有 2 个其它异常**才确定异常 |
| 20 ~ 35℃ | 轻度疑似异常 | **再有 3 个其它异常**才确定异常 |
| 36 ~ 37℃ | 无异常 | 直接排除 ✓ |

> 两张表是同一个结构 ✓：**证据越弱，需要的旁证越多** ✓。这一条要和现在的「异常读数 N 条互相印证」对齐 ✓
> （`CaseDirector.corroborationNeeded` ✓）—— 目前是"凑够 N 条就行"✗，按新口径应该是"每条异常自己带权重 ✓，加权够数才成立" ✓。

## 3. 关卡与交互点（2D 画面 + 交互点清单）

### 3.1 后院（雨夜）

画面：老旧后院，斑驳木门、长满杂草的花坛、昏暗走廊灯。
可交互点：**花坛、走廊配电箱、后院木门**。

**交互点 1：配电箱**
- 表面描述：生锈的配电箱，里面有几个开关。
- 道具交互：点击**工具包** → 打开配电箱。
- 陷阱：用工具包可**暂时关闭**配电箱 ✓，从而屏蔽别墅内监控与警报 ✓。
  若**未关电闸**直接进去 → 触发警报 ✓，每次 **-3 SAN** ✓，SAN 清零 = 任务失败 ✓。

**交互点 2：花坛泥土**
- 表面描述：泥土中露出半截金属表带，看起来是一块男士手表。
- 温度枪 → 显示温度（**8℃ / 24℃** 随机 ✓）
- 便携式探测器 → EMF（**4 级 / 1 级** 随机 ✓）
- 手 → 拿起手表
- **伪人版**：温度 8℃ + EMF 4 级 ✓；拿起时远处传来玻璃破碎声 ✓；**没放进收容箱 → -2 SAN** ✓。
- **人类版**：温度 24℃ + EMF 1 级 ✓；拿起时风吹动树叶 ✓；无属性变化 ✓；获得【李阳的手表】✓。

### 3.2 客厅（从后院侧门进入）

画面：复古装修，深色皮质沙发、水晶吊灯、满墙书架，空气里有玫瑰香水味。
可交互点：**茶几、天花板西南角、书架底层、客厅大门 / 沙发**。

**交互点 1：茶几抽屉** — 没上锁。
- 手 → 打开抽屉，拿出一张**星途科技团建合影**。
- 紫外线灯 → 照射合影。
- **伪人版**：7 名失踪者脸上有**红色荧光叉号** ✓；没放进收容箱 → **-2 SAN** ✓。
- **人类版**：无异常 ✓；无属性变化 ✓；获得【普通团建合影】✓。

**交互点 2：天花板西南角**
- 紫外线灯 → 显示监控。
- **伪人版**：有**红色手印** ✓；用工具包破坏后客厅灯光闪烁 3 次 ✓；没破坏 → **-2 SAN** ✓。
- **人类版**：无手印 ✓；破坏后无异常 ✓；获得【损坏的安防摄像头】✓。

**交互点 3：书架底层**（密封玻璃瓶）
- 温度枪 → 温度（**-2℃ / 23℃** 随机 ✓）
- 录音笔 → 录制声音
- 收容箱 → 收容物品
- **伪人版**：温度 -2℃ + 录到**低频嗡鸣** ✓；拿起时瓶身结冰 ✓；没放进收容箱 → **-2 SAN** ✓。
- **人类版**：温度 23℃ + 无异常声音 ✓；标签写着「生物实验样本」✓；无属性变化 ✓。

**交互点 4：沙发**（残存红酒酒渍与些许长发）
- 录音笔 → 录制声音
- 便携式探测器 → **出现 CG**
- **伪人版**：EMF **5 级** ✓；CG = 女人半躺沙发、红酒杯里盛着血、脸上和衣服上有血迹、表情癫狂 ✓；
  录音笔里是男性嘶吼惨叫 ✓；没放进收容箱 → **-2 SAN** ✓。
- **人类版**：EMF **2 级** ✓；CG = 女人半躺沙发、杯里是白葡萄酒、脸上有红晕、其余正常 ✓；录音里有正常女性呼吸声 ✓。
